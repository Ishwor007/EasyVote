EasyVote – Blockchain-Based E-Voting System
EasyVote is a secure and transparent electronic voting platform that leverages blockchain technology to ensure the integrity and immutability of votes. Designed to modernize the electoral process, EasyVote allows voters to cast their ballots from anywhere, reducing logistical challenges and enhancing participation.

🔐 Key Features
Blockchain Integration: Utilizes blockchain to record votes, ensuring transparency and preventing tampering.

Secure Authentication: Implements mechanisms to verify voter identity and eligibility.

User-Friendly Interface: Provides an intuitive interface for voters to cast their votes effortlessly.

Real-Time Results: Offers immediate access to voting results, enhancing trust in the electoral process.

🛠️ Technologies Used
Backend: Java, Spring Boot

Frontend: HTML, CSS

Database: MySQL

Version Control: Git

📂 Project Structure
src/: Contains the source code for the application.

pom.xml: Maven configuration file for managing project dependencies.

.gitignore: Specifies files and directories to be ignored by Git.
